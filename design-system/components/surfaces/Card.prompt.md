Rounded (20px) warm container. Border-hairline + soft warm shadow; never a colored left border.

```jsx
<Card tone="pulpa" eyebrow="Ingrediente" title="Lulo entero, no extracto">
  <p>La fruta completa conserva la vitamina C y los antioxidantes que la pulpa ya traía.</p>
</Card>
```

Tones: `plain` default, `tint` for brand emphasis, `pulpa` for science/nature notes, `inverse` for closing statements.

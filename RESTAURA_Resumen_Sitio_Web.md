# RESTAURA — Los 8 Frentes

Resumen para el proyecto de sitio web (restaura.do) · 3 de agosto de 2026

RESTAURA es el marco de ocho frentes que estructura el instrumento de evaluación de vida y
liderazgo. Cada nombre se diseñó para leerse sin necesitar explicación y para funcionar bajo
cualquier metáfora de presentación (taller, relojero, o ninguna), de forma que el sitio pueda
usar la narrativa visual que convenga sin cambiar el contenido de fondo.

## Los ocho frentes

| Letra | Nombre | Qué cubre |
|---|---|---|
| R | Respaldo | Finanzas, patrimonio, base material |
| E | Energía | Salud física, vitalidad, descanso |
| S | Sentido | Propósito, motivación interior |
| T | Trayectoria | Trabajo, carrera, ingresos |
| A | Alineación | Visión, valores, dirección |
| U | Unidad | Relaciones cercanas |
| R | Resiliencia | Estado mental y emocional |
| A | Autoridad | Imagen, reputación |

## Por qué el orden importa

R-E-S-T-A-U-R-A no es alfabético por conveniencia, cuenta el proceso de una restauración real:
se examina primero la base (Respaldo), se reúne la energía para actuar (Energía), se encuentra
el porqué (Sentido), se convierte ese porqué en un camino concreto (Trayectoria), se verifica
que ese camino esté alineado con los valores propios (Alineación), se sostiene con las personas
cercanas (Unidad) y con la capacidad interior de resistir (Resiliencia), y al final aparece la
autoridad, que es resultado y no punto de partida (Autoridad). Útil como hilo narrativo si el
sitio presenta los frentes en secuencia en vez de como lista plana.

## Dos principios sin frente propio

Fe: no es un frente aislado, es transversal a los ocho. No se nombra explícitamente porque el
público es secular, pero conviene que el sitio no la reduzca a un solo frente si en algún
momento se explica la filosofía detrás del instrumento.

Descanso: no tiene frente propio, vive dentro de Energía. Si el sitio profundiza en cada
frente, Energía debería mencionar descanso explícitamente y no solo salud física.

## Nota de uso

El instrumento evalúa cada frente con tres formatos posibles: escenarios de decisión, diales de
frecuencia, y pares de elección forzada. La regla del producto es no dar retroalimentación por
frente de forma aislada; la interpretación profunda queda reservada para el reporte final y los
productos pagos. Si el sitio incluye una vista previa o demo, debe respetar esa regla y no
adelantar interpretación por frente suelto.
